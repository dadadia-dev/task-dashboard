### つまずいたこと：npmが動かない
- 症状：`npm -v` で「スクリプトの実行が無効」というエラー
- 原因：npmはPowerShellからは `npm.ps1`（スクリプト）として呼ばれる。Windowsの既定の実行ポリシーは `Restricted` で、スクリプトの実行を禁止している
  - `Get-ExecutionPolicy -List` が全部 `Undefined` ＝ 指定なし ＝ 既定の `Restricted` 扱い
- 対処：自分のユーザーだけ `RemoteSigned` に変更
  ```
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  ```
  - `RemoteSigned`：ローカルのスクリプトは実行可、ネットから落とした未署名スクリプトは止める
  - `-Scope CurrentUser`：PC全体ではなく自分のユーザーだけに効く

### Gitの初期設定
- Gitはコミットごとに「誰が変更したか（名前・メール）」を記録する
- 公開リポジトリではコミットのメールアドレスが誰でも見られるため、GitHubのnoreplyアドレスを使う
  - GitHub → Settings → Emails →「Keep my email addresses private」
  ```
  git config --global user.email "294998407+dadadia-dev@users.noreply.github.com"
  git config --global init.defaultBranch main
  ```
- `git config --global --list` で設定を確認できる
- `filter.lfs.…` はGit LFS（大きなファイル用の拡張）の設定。Git for Windowsで自動的に入るもの

## 段階1：雛形作成とデータ読み込み

### Viteで雛形を作る
```
npm create vite@latest . -- --template react
npm install
npm run dev
```
- 空でないフォルダでは「Ignore files and continue」を選ぶ（Removeは既存ファイルが消える）
- create-vite は自分の `.gitignore` で既存のものを上書きした → `git diff .gitignore` で気づいて `private/` の行を戻した。区切りでコミットしておくと差分で確認できる
- `node_modules/` は `npm install` でいつでも作り直せるのでGitに入れない。`package-lock.json` は入れる
- HMR：保存した瞬間に、リロードなし・状態を保ったまま画面が更新される

### ファイルのつながり
`index.html`（`<div id="root">`）→ `src/main.jsx`（root に App を描画）→ `src/App.jsx`（画面の本体）

### Excel → JSON
- `python scripts/convert_tasks.py` で2つ出力
  - `src/data/tasks.local.json`：実データ（Gitに入れない）
  - `src/data/tasks.sample.json`：ダミー（公開用）
- 置き換えルールと禁止語は `private/dummy_rules.json`（実名を含むので非公開）
- 禁止語が残っていたら書き出さずに止まる安全装置つき。ただしリストにない語は見つけられないので、目視確認が必要

### Reactで表示する
- `import.meta.glob`（Viteの機能）：ファイルがあれば読み、なければ空 → 実データが無い環境（Vercel）では自動でダミーになる
- コンポーネント：画面の部品。`TaskTable` を作り、App から `tasks={...}` で渡す（props）
- `tasks.map(...)` で配列を行に変換。各行に `key` を付ける

### Gitのつまずき
- `git add` はその時点の内容を控えるだけ。あとでファイルを変えたら add し直す
- `git status --short` の `MM`：ステージ後にさらに変更あり、`AD`：ステージ後に削除
- Pythonのキャッシュ `__pycache__/` は `.gitignore` に入れる

## 段階2：業務マップ画面

### 作ったもの
- 分類別の月間時間（横棒グラフ）：`CategoryChart.jsx`、グラフ部品は Recharts（`npm install recharts`）
- 属人度×自動化・委任の余地のマトリクス（3×3）：`MatrixChart.jsx`、ライブラリなしで自作
- マスをクリックすると一覧が絞り込まれる

### 学んだこと
- 集計は表示の直前に計算する。JSONは元データだけ持つ → Excelを更新して変換し直せばグラフも正しくなる
- 状態（どのマスを選んだか）は、それを使う部品たち（マトリクスと一覧）の共通の親＝App が `useState` で持つ。子には props で値と「変更する関数」を渡す
- 色は意味で決める。量の大小は1色の濃淡。ダークモードでは「少ない＝背景に近い色」になるよう向きを入れ替える
- Recharts は SVG で描くので、CSSでは `color` ではなく `fill` で色を付ける
- ビルド時の「500kBを超える」警告は Recharts が大きいため。今の規模なら対応不要

## 段階3：GitHubへpush → Vercelで公開

### GitHubへ送る
```
git remote add origin https://github.com/dadadia-dev/task-dashboard.git
git push -u origin main
```
- GitHubでリポジトリを作るときは README・.gitignore・license を付けない（手元の履歴と食い違ってpushが拒否される）
- `remote`：送り先の住所に名前（慣例で `origin`）を付けて登録する
- `-u`：main と origin/main をひもづける。次回からは `git push` だけでよい
- Privateリポジトリは、権限のない相手には「Repository not found」と表示される
- 公開前に、全履歴に実名やメールアドレスが含まれていないか確認した

### Vercelで公開
- Add New → Project（`vercel.com/new`）→ GitHub を選び、Vercel の GitHub App を「Only select repositories」で task-dashboard だけに許可
- Framework Preset は Vite を自動判定。Build Command `npm run build`、Output `dist`
- Vercel の中では「GitHubから取得 → npm install → npm run build → dist/ を配信」が行われる
- 公開URL：https://task-dashboard-phi-ochre.vercel.app/
- 公開ページのJSファイルを取得して、実名が含まれていないことを確認した（`tasks.local.json` は存在しない＝ダミー版）
- 以後は `git push` するだけで、Vercelが自動でビルドして公開ページを更新する
